🛍️ Customer Segmentation using K-Means Clustering
📌 Task 02

Create a K-means clustering algorithm to group customers of a retail store based on their purchase history.

📖 Project Overview

This project implements the K-Means clustering algorithm to segment customers of a retail mall based on their Annual Income and Spending Score.
Customer segmentation helps businesses understand customer behavior and design better marketing strategies.

🎯 Objective

1.To analyze customer purchase behavior

2.To group customers into meaningful clusters

3.To visualize customer segments using graphs

🛠️ Technologies Used

2.Visual Studio Code

Age                                 	Age of the customer
Annual Income (k$)	                  Annual income in thousand dollars
Spending Score (1-100)              	Customer spending behavior

⚙️ How to Run the Project
Step 1: Install Python

Ensure Python 3.x is installed and added to PATH.

Step 2: Install Required Libraries

Run this command in the terminal:
python -m pip install pandas numpy matplotlib seaborn scikit-learn

Step 3: Run the Program

Navigate to the project folder and execute:
python kmeans_customer_segmentation.py


📈 Output
1.Elbow Method graph to find the optimal number of clusters

2.Scatter plot visualization showing customer segments

3.Customers grouped into 5 clusters

🧠 Result
The K-Means algorithm successfully clusters customers based on income and spending behavior.
This segmentation helps identify:

1.High-value customers

2.Low-spending customers

3.Average customers

📝 Conclusion
Customer segmentation using K-Means provides valuable insights into customer behavior and supports data-driven business decisions. The visualizations make it easy to understand and interpret customer groups.
